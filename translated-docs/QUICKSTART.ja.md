## インストール

このリポジトリのリリース (Releases) ページからビルドをダウンロードしてください。

**Windows.** `CursorPace-*-win-x64-setup.exe` を実行します。SmartScreen がアプリが未署名であると警告した場合は、**詳細情報** を選択し、次に **実行** を選択します。**サインイン** には [Microsoft Edge WebView2 Runtime](https://go.microsoft.com/fwlink/p/?LinkId=2124703) が必要です。不足している場合、インストーラーはダウンロードページを提示します。

**Linux.** ほとんどのディストリビューションでは、`chmod +x CursorPace-*-linux-x64.AppImage` (または `linux-arm64` ファイル) を実行します。Debian または Ubuntu では、`sudo apt install ./CursorPace-*-linux-x64.deb` (または `linux-arm64`) が GTK と WebKit を取り込みます。WebKit では Google サインインがブロックされる場合があります。GitHub、メールを使用するか、Windows でサインインしてください。

**macOS.** `CursorPace-*-osx-arm64.dmg` (Apple Silicon) または `*-osx-x64.dmg` (Intel) を開き、`CursorPace.app` を「アプリケーション」にドラッグします。Gatekeeper が未署名アプリをブロックする場合、一度 **開く** を右クリックし、次に **システム設定 → プライバシーとセキュリティ** で **とにかく開く** を選択します。

## 初回実行

**通知トレイに表示** はデフォルトでオンになっているため、初回起動時にはトレイアイコンのみが表示される場合があります。そのアイコンからウィンドウを開くか、`--show` で起動します。

1. **サインイン** を選択します。
2. 埋め込みウィンドウで Google、GitHub、または二段階認証によるサインインを完了します。Cursor がセッションを受け入れると、ウィンドウは閉じます。すでにアカウントが表示されている場合は、**続行** を選択します。
3. 請求サイクルと使用状況がグラフに表示されます。

後で **設定** → **Cursorアカウント** からサインインできます。更新が成功すると、その見出しは **Cursorアカウント (接続済み)** と表示されます。タイトルバーの **更新**、または設定の **今すぐ更新** を選択すると、すぐにデータが取得されます。

**サインアウト** は Cursor セッションをクリアします。Windows および macOS では、保存された Google または GitHub のログイン情報が残る場合があるため、次回のサインイン時にパスワードがスキップされることがあります。Linux では、**サインアウト** はブラウザプロファイル全体をクリアします。使用状況のサンプルはディスクに残ります。

**使用状況を自動的に更新** がオンの場合、更新は現地時間の深夜から 1、2、4、6、または 12 時間ごとに実行されます。起動時、更新は、最後の成功から少なくとも 20 分が経過し、かつスケジュールされたスロットがスキップされたか、または完全な間隔がすでに経過した場合にのみ実行されます。

## メインウィンドウ

</p>

グラフの上には 3 つのカードがあります:

- **サイクル開始** と **次回更新**。現在のサイクルでは、更新日の横に残りの時間が表示されます。
- 各モデルの予測。サイクル内では、これは使い切りまでの時間です。破線で示された予想ラインより上では、そのラインが読み取り値に追いつく時期です。ライン上またはラインより下では、更新時の予測パーセンテージです。現在のサイクルでは、日付の横に待機時間が含まれます。
- **最終測定**: このサイクルにおける最新のサンプルで、Cursor %、その他 %、予想される使用状況 %、および各シリーズがそのペースからどれだけ離れているかを示します。

月見出しの「前へ」と「次へ」で、保存されたサイクルを移動します。その見出しの下に、`Cursor dd-MMM HH:mm` が最新の更新です。赤い点は、アカウントがサインアウトされているか、更新に失敗したことを意味します。クリックすると **Cursorアカウント** が開きます。同期サーバーが設定されている場合、**同期サーバー** とその最終成功時刻もそこに表示されます。赤い点は、最後の試行が失敗したことを意味します。クリックすると **同期サーバー** が開きます。

| 範囲 | 表示内容 |
| --- | --- |
| **1日** / **2D** | 過去 24 時間または 48 時間 |
| **7D** / **1W** | 過去7日間 |
| **2W** | 過去14日間 |
| **1M** | 表示されているサイクル全体、ローカル日ごとに1つのサンプル |

ライブサイクルでは、短い範囲が現在時刻で終了します。以前のサイクルでは、そのサイクルの更新時に終了します。ウィンドウがそれより早く開始される場合でも、開始はサイクル開始時に留まります。

プロットをドラッグしてズームします。右クリックで**1M**に戻ります。すでに選択されているものを含め、範囲ボタンを選択すると、ズームが解除され、その範囲が表示されます。**までのすべてのサンプル** (**2D**、**4D**、**7D**、または**14D**、デフォルトは**14D**) は、チャートがすべてのサンプルをプロットする範囲と、ローカル時刻のラベルを設定します。より長い範囲では、各日の最後のサンプルが保持され、月の日のラベルが付けられます。垂直軸は、画面上の値を最大120%まで表示します。

ポインターを移動すると、その時点でのCursor、その他のモデル、および予想される使用状況を読み取ることができます。最後のサンプルを過ぎると、Cursorとその他には`estimated`とマークされた推定値が表示されます。ズーム中には、読み取り値にはズーム開始時の各値とそこからの変化も表示されます。

| コントロール | アクション |
| --- | --- |
| **リフレッシュ** | Cursor の使用状況を現在取得します。設定ページでは非表示です。 |
| **設定** | このウィンドウで設定を開く |
| **戻る** | チャートに戻ります |
| **最小化** / **最大化** | 標準のウィンドウコントロール。アプリはトレイに残ります |
| 閉じる | ウィンドウを非表示にします。アプリはトレイに残ります |

ウィンドウは、そのサイズ、位置、および最大化された状態を記憶します。情報ラベルは選択してコピーできます。

## 予想と推定

- チャート上の**予想される使用状況**は、サイクル開始時に0%から次回更新時に100%までの破線です。ホバーはこの線を使用します。
- **Cursor**と**その他のモデル**は、測定されたサンプルです。
- サイクルCSVにおける**予想**は、各サンプルに続き、残りのクォータを更新時に100%になるように調整します。
- **推定**は、最後のサンプルから更新に向かう丸い点線の予測です。最後のサンプル以降は、ホバーはこの線を使用します。

Cursorモデルとその他のモデルは独立しています。

## 設定

設定を開くと、チャートは設定画面に置き換わります。**戻る**、または**設定**の見出しを選択すると、チャートに戻ります。最後に開いたタブは、再起動後も含め、次回も開きます。

**同期サーバー**はオプションです。[CursorPace同期サーバー](https://github.com/wsj-br/CursorPace-SyncServer) は、ローカルネットワーク上のマシン間で利用状況のサンプルと請求サイクルの境界を共有します。これにより、同じ開発環境にあるMac、Windows PC、Linuxマシンで同じチャートが表示されます。そのリポジトリからサーバーをインストールして実行してください。テーマ、言語、ウィンドウの配置、起動オプションは各コンピューターに保持されます。

| タブ | 設定できる項目 |
| --- | --- |
| 起動と表示 | **ログイン時に起動**、**通知トレイに表示**、テーマ（システム、ライト、またはダーク）、**言語**（`locales/ui-languages.json`内のロケール、またはそのファイルがない場合は英語）、および**までのすべてのサンプル** |
| Cursorアカウント | **サインイン** (接続中は非表示)、**今すぐ更新**、**サインアウト**、および1、2、4、6、または12時間ごとの自動更新 |
| 同期サーバー | **サーバーと同期**、サーバーURL、APIトークン、マシン名 (デフォルトではホスト名)、および**今すぐ再同期**。このリンクは同期サーバーのリポジトリを開きます |
| エクスポートとバックアップ | 画面に表示されているサイクルについて**サイクルCSVをエクスポート**、サインイン中に保存されたすべてのサンプルについて**使用状況をエクスポート**、および設定とサンプルを1つのzipファイルとして**バックアップ**/**復元**。**フォルダーを開く**は保存先を開きます |
| バージョン情報 | バージョン、UTCビルド日時、著作権、MITライセンス、およびGitHubリポジトリ |

バックアップと復元を行っても、このマシン上のCursorサインイン情報は保持されます。

## トレイ

アイコンをクリックするか、**開く**を選択すると、ウィンドウが表示されます。**終了**で終了します。ツールチップには今日のパーセンテージが表示され、十分なデータがある場合は、更新時の予測パーセンテージが表示されます。

macOSでは、クリックするとトレイメニューが開き、ウィンドウが非表示または最小化されている間はDockアイコンが非表示になります。トレイから、`--show`で、またはアプリを再度起動することで、ウィンドウを表示できます。

アイコンが見つからない場合は、通知オーバーフローを開いてください。GNOMEでは、AppIndicator拡張機能が必要になる場合があります。

2回目の起動では、すでに実行中のウィンドウが表示されます。2回目の`--background`起動では、ウィンドウは非表示のままになります。`--show`はウィンドウを強制的に開きます。**ログイン時に起動**は**通知トレイに表示**に従います。

## データ

```text
Windows: %LocalAppData%\CursorPace\
Linux:   ~/.local/share/CursorPace/
macOS:   ~/Library/Application Support/CursorPace/
```

`settings.json`には、設定、ウィンドウの配置、およびサイクル範囲が保持されます。`usage-samples.json`にはサンプルが保持されます。Cursorのサインイン情報は、Windowsでは`WebView2`、LinuxおよびmacOSでは`WebView`、Linux AppImageを実行している場合は`WebView-AppImage`に保存されます。解析できないファイルは`*.corrupt.json`にコピーされ、空のファイルに置き換えられます。ロックされている、または読み取り不可能なファイルはそのまま残されます。

最初からやり直すには、フォルダーを削除してください。Windowsでは、アプリをアンインストールすると削除されます。LinuxおよびmacOSでは、手動で削除してください。

## 更新

新しいサイクル開始を報告するフェッチは、前回サイクルをアーカイブし、そのサンプルを保持します。「前へ」と「次へ」でそれらのサイクルが開きます。アプリは、ローカルの日付が保存されている更新日に達すると、更新されます。ウィンドウは非表示のままにできます。そのチェックと自動更新のためには、プロセスが実行されている必要があります。

## アンインストール

トレイメニューから終了します。Windowsでは、**インストールされているアプリ**から**CursorPace**をアンインストールします。LinuxおよびmacOSでは、アプリを削除し、クリーンな状態から始めるには、上記のデータフォルダーを削除します。

## トラブルシューティング

**アプリが起動しません。** すべての`CursorPace`プロセスを終了し、再度起動してください。Windowsでは、イベントビューアーを確認してください。Linuxでは、`journalctl --user -xe`を試してください。macOSでは、Console.appを確認してください。LinuxでCPU使用率が100%になる場合、または`crash.log`が`Could not create glyphTypeface`と表示される場合は、0.3.0より新しいリリースをインストールしてください。**ログイン時に起動**が削除されたAppImageを指している場合は、新しいAppImageを一度実行してください。

**サインインに失敗するか、「指定されたモジュールが見つかりません」と表示されます。** Windowsでは、[WebView2 Runtime](https://go.microsoft.com/fwlink/p/?LinkId=2124703) (Evergreen x64) をインストールしてください。Linuxでは、`libwebkit2gtk-4.1-0`をインストールしてください。Googleが組み込みブラウザをブロックする場合は、GitHubまたはメールを使用してください。Cursorアカウントがすでに画面に表示されている場合は、**続行**を選択してください。

**利用状況が更新されません。** **Cursorアカウント (接続済み)** と自動更新を確認するか、**更新**を選択してください。システムの日付、時刻、およびタイムゾーンを確認してください。Cursorのレート制限後、アプリは次のインターバルまで待機します。

**トレイまたはタスクバーのアイコンが表示されない。** 通知オーバーフローを開いてください。Linuxでは、`~/.local/share/applications/CursorPace.desktop`を書き込めるようにアプリを再起動してください。タスクバーのアイコンがまだ一般的な歯車のままであれば、一度ログアウトするか、X11でAlt+F2を押して`r`と入力し、Enterを押してください。

**設定が保存されない、または今日のパーセンテージが正しくない。** データフォルダーに書き込みができることを確認してください。`settings.corrupt.json`が存在する場合は、それを削除し、`settings.json`も削除してリセットしてください。その後、時計を確認し、**更新**を選択してください。

**ログイン時に起動が機能しない。** 設定がオンになっていることを確認してください。Windowsは、現在のユーザーのRunキーに`CursorPace`を保存し、トレイ起動がオンの場合に`--background`を追加します。署名されたmacOSアプリは、**ログイン時に開く**の下に表示されます。署名されていないビルドは`~/Library/LaunchAgents/com.cursorpace.app.plist`を使用し、`/usr/bin/open`で`.app`を起動します。Linuxは`~/.config/autostart/cursor-pace.desktop`を使用します。AppImageのエントリは`.AppImage`ファイルを指している必要があります。設定をオフにしてからオンにするか、新しいAppImageを一度起動して、それを書き換えてください。

**トレイアイコンが２つ表示される、またはLinuxの再起動後にサインアウトされる。** トレイから終了し、アプリをもう一度起動してください。Linuxでは、`cookies.sqlite`にセッションが保存されるように、最新ビルドで再度サインインしてください。
