## 安裝

從此儲存庫的「發行頁面」下載建置版本。

**Windows。** 執行 `CursorPace-*-win-x64-setup.exe`。如果 SmartScreen 警告應用程式未簽署，請選擇 **更多資訊**，然後選擇 **仍要執行**。**登入** 需要 [Microsoft Edge WebView2 Runtime](https://go.microsoft.com/fwlink/p/?LinkId=2124703)。如果缺少，安裝程式會提供下載頁面。

**Linux。** 對於大多數發行版，請使用 `chmod +x CursorPace-*-linux-x64.AppImage` (或 `linux-arm64` 檔案) 並執行它。在 Debian 或 Ubuntu 上，`sudo apt install ./CursorPace-*-linux-x64.deb` (或 `linux-arm64`) 會引入 GTK 和 WebKit。Google 登入可能會在 WebKit 中被封鎖；請使用 GitHub、電子郵件，或在 Windows 上登入。

**macOS。** 開啟 `CursorPace-*-osx-arm64.dmg` (Apple Silicon) 或 `*-osx-x64.dmg` (Intel) 並將 `CursorPace.app` 拖曳到「應用程式」。如果 Gatekeeper 封鎖未簽署的應用程式，請右鍵按一下 **開啟** 一次，然後在 **系統設定 → 隱私權與安全性** 中選擇 **仍要開啟**。

## 首次執行

**在通知區域中開始** 預設為開啟，因此首次啟動可能只會顯示通知區域圖示。從該圖示開啟視窗，或使用 `--show` 啟動。

1. 選擇 **登入**。
2. 在內嵌視窗中完成 Google、GitHub 或雙因素登入。當 Cursor 接受工作階段時，它會關閉。如果您已看到您的帳戶，請選擇 **繼續**。
3. 帳單週期和使用量會顯示在圖表上。

您可以稍後從 **設定** → **Cursor 帳戶** 登入。成功更新後，該標題會顯示 **Cursor 帳戶 (已連線)**。標題列中的 **重新整理**，或「設定」中的 **立即重新整理**，會立即擷取。

**登出** 會清除 Cursor 工作階段。在 Windows 和 macOS 上，已儲存的 Google 或 GitHub 登入資訊可能會保留，因此下次登入可能會跳過該密碼。在 Linux 上，**登出** 會清除整個瀏覽器設定檔。使用量樣本會保留在磁碟上。

當 **自動更新用量** 開啟時，重新整理會在當地午夜後的 1、2、4、6 或 12 小時標記時進行。啟動時，只有在上次成功重新整理已超過 20 分鐘，且錯過了排定的時段或整個間隔已過時，才會執行重新整理。

圖表上方有三個卡片：

- **週期開始**與**下次續訂**。在現行週期中，剩餘時間顯示在續訂日期旁。
- 每個型號的預測。在週期內，此為耗盡時間。在虛線預期線上方時，代表該線追上讀數的時間；在線上或線下時，則為續訂時的預估百分比。在現行週期中，日期旁會顯示等待時間。
- **上次測量**：此週期內的最新樣本，包含 Cursor 百分比、其他百分比、預期使用量百分比，以及各系列與該進度的差距值。

月份標題上的「上一個」和「下一個」會瀏覽儲存的週期。在該標題下方，`Cursor dd-MMM HH:mm` 是最新的重新整理。紅點表示帳戶已登出或重新整理失敗。按一下它以開啟 **Cursor 帳戶**。當同步伺服器已設定時，**同步伺服器** 及其上次成功時間也會顯示在那裡。紅點表示上次嘗試失敗。按一下它以開啟 **同步伺服器**。

| 範圍 | 顯示內容 |
| --- | --- |
| **1 天** / **2 天** | 過去 24 或 48 小時 |
| **7 天** / **1 週** | 過去七天 |
| **2 週** | 過去 14 天 |
| **1 個月** | 整個顯示週期，每個當地日期一個樣本 |

在即時週期中，短範圍結束於目前時間。在較早的週期中，它結束於該週期的續訂時間。當視窗原本會更早開始時，開始時間會保持在週期開始。

拖曳圖表以縮放。右鍵點擊可返回 **1 個月**。選擇範圍按鈕，包括已選取的按鈕，會離開縮放並顯示該範圍。**每個樣本最長** (**2 天**、**4 天**、**7 天** 或 **14 天**，預設為 **14 天**) 設定圖表繪製每個樣本的距離並標示當地時間。較長的範圍會保留每天的最後一個樣本並標示月份中的日期。垂直軸會將螢幕上的值調整至適合，最高可達 120%。

移動指標以讀取該時間的 Cursor、其他模型和預期使用量。超過最後一個樣本後，Cursor 和其他模型會顯示估計值，標記為 `estimated`。在縮放期間，讀數也會顯示縮放開始時的每個值以及從該處的變化。

| 控制 | 動作 |
| --- | --- |
| **重新整理** | 立即擷取 Cursor 使用量。在「設定」頁面中隱藏 |
| **設定** | 在此視窗中開啟「設定」 |
| **返回** | 返回圖表 |
| **最小化** / **最大化** | 標準視窗控制項。應用程式會保留在通知區域中 |
| 關閉 | 隱藏視窗。應用程式會保留在通知區域中 |

視窗會記住其大小、位置和最大化狀態。資訊標籤可以選取和複製。

## 預期與估計

- **預期使用量** 在圖表上是從週期開始的 0% 到下次續訂的 100% 的虛線。懸停時會使用此線。
- **Cursor** 和 **其他模型** 是測量的樣本。
- 週期 CSV 中的 **預期** 會跟隨每個樣本，然後將剩餘配額調整至續訂時的 100%。
- **估計** 是從最後一個樣本到續訂的圓點投影。超過最後一個樣本後，懸停時會使用此線。

Cursor 和其他模型保持獨立。

## 設定

「設定」會取代圖表。**返回** 或「**設定**」標題會返回圖表。上次開啟的分頁會在下次重新開啟，包括重新啟動後。

**同步伺服器** 是選用的。[CursorPace 同步伺服器](https://github.com/wsj-br/CursorPace-SyncServer) 在區域網路上的機器之間共用使用量樣本和計費週期界限，因此在相同開發環境中的 Mac、Windows PC 和 Linux 機器會顯示相同的圖表。從該儲存庫安裝並執行伺服器。主題、語言、視窗位置和啟動選項會保留在每台電腦上。

| 分頁 | 您可以設定的項目 |
| --- | --- |
| 啟動與顯示 | **登入時啟動**、**在通知區域中開始**、主題 (系統、淺色或深色)、**語言** (`locales/ui-languages.json` 中的地區設定，或當該檔案遺失時為英文)，以及 **每個樣本最長** |
| Cursor 帳戶 | **登入** (連線時隱藏)、**立即重新整理**、**登出**，以及每 1、2、4、6 或 12 小時自動重新整理 |
| 同步伺服器 | **與伺服器同步**、伺服器 URL、API 權杖、機器名稱 (預設為主機名稱)，以及**立即重新同步**。此連結會開啟同步伺服器儲存庫 |
| 匯出與備份 | 針對螢幕上顯示的週期**匯出週期 CSV**、針對登入時儲存的每個樣本**匯出用量**，以及將設定和樣本**備份**/**還原**為一個壓縮檔。**開啟資料夾**會開啟目的地 |
| 關於 | 版本、UTC 建置日期和時間、著作權、MIT 授權條款，以及 GitHub 儲存庫 |

備份和還原會保留此機器上的 Cursor 登入資訊。

## 通知區域

按一下圖示，或選擇**開啟**，以顯示視窗。**結束**會關閉應用程式。工具提示會顯示今日的百分比，並且在有足夠資料後，顯示續訂時的預計百分比。

在 macOS 上，按一下會開啟通知區域選單，且當視窗隱藏或最小化時，Dock 圖示會隱藏。從通知區域、使用 `--show` 或再次啟動應用程式來顯示視窗。

如果圖示遺失，請開啟通知溢位區。在 GNOME 上，可能需要 AppIndicator 擴充功能。

第二次啟動會顯示已在執行的視窗。第二次 `--background` 啟動會使其保持隱藏。`--show` 會強制開啟視窗。**登入時啟動**會遵循**在通知區域中開始**的設定。

## 資料

```text
Windows: %LocalAppData%\CursorPace\
Linux:   ~/.local/share/CursorPace/
macOS:   ~/Library/Application Support/CursorPace/
```

`settings.json` 儲存偏好設定、視窗位置和週期範圍。`usage-samples.json` 儲存樣本。Cursor 登入資訊位於 Windows 上的 `WebView2`、Linux 和 macOS 上的 `WebView`，或執行 Linux AppImage 時的 `WebView-AppImage`。無法解析的檔案會複製到 `*.corrupt.json` 並替換為空白檔案。鎖定或無法讀取的檔案會保持原樣。

刪除資料夾以重新開始。在 Windows 上，解除安裝應用程式會將其移除。在 Linux 和 macOS 上，請自行刪除。

## 續訂

報告新週期開始的擷取會封存上個週期並保留其樣本。「上一個」和「下一個」會開啟這些週期。當本地日期達到儲存的續訂日期時，應用程式也會重新整理。視窗可以保持隱藏。該程序必須執行才能進行檢查和自動更新。

## 解除安裝

從通知區域選單結束。在 Windows 上，從**已安裝的應用程式**解除安裝 **CursorPace**。在 Linux 和 macOS 上，刪除應用程式，並為了全新開始，刪除上述資料夾。

## 疑難排解

**應用程式無法啟動。** 結束任何 `CursorPace` 程序並再次啟動。在 Windows 上，檢查事件檢視器。在 Linux 上，嘗試 `journalctl --user -xe`。在 macOS 上，檢查 Console.app。如果 Linux 佔用 100% CPU，或 `crash.log` 顯示 `Could not create glyphTypeface`，請安裝比 0.3.0 更新的版本。如果**登入時啟動**仍指向已刪除的 AppImage，請執行新的 AppImage 一次。

**登入失敗，或「找不到指定的模組」。** 在 Windows 上，安裝 [WebView2 Runtime](https://go.microsoft.com/fwlink/p/?LinkId=2124703) (Evergreen x64)。在 Linux 上，安裝 `libwebkit2gtk-4.1-0`。如果 Google 封鎖內嵌瀏覽器，請使用 GitHub 或電子郵件。當您的 Cursor 帳戶已顯示在螢幕上時，選擇**繼續**。

**用量未更新。** 確認**Cursor 帳戶 (已連線)** 和自動更新，或選擇**重新整理**。檢查系統日期、時間和時區。在達到 Cursor 速率限制後，應用程式會等待下一個間隔。

**系統匣或工作列圖示遺失。** 開啟通知溢位區。在 Linux 上，重新啟動應用程式，使其可以寫入 `~/.local/share/applications/CursorPace.desktop`。如果工作列圖示仍是通用齒輪圖示，請登出一次，或在 X11 上按下 Alt+F2，輸入 `r`，然後按下 Enter。

**設定未儲存，或今日百分比看起來不正確。** 確認您可以寫入資料夾。如果 `settings.corrupt.json` 存在，請刪除它和 `settings.json` 以重設。然後檢查時鐘並選擇 **重新整理**。

**登入時啟動**沒有作用。確認此設定已開啟。Windows 會將 `CursorPace` 儲存在目前使用者的 Run 機碼中，並在系統匣啟動開啟時新增 `--background`。已簽署的 macOS 應用程式會出現在 **登入時開啟** 下方。未簽署的版本會使用 `~/Library/LaunchAgents/com.cursorpace.app.plist` 並以 `/usr/bin/open` 啟動 `.app`。Linux 使用 `~/.config/autostart/cursor-pace.desktop`。AppImage 項目必須指向 `.AppImage` 檔案。關閉再開啟此設定，或啟動新的 AppImage 一次，以重新寫入它。

**兩個托盤圖示，或在 Linux 重新啟動後登出。** 從托盤退出並啟動應用程式一次。在 Linux 上，在目前的版本上再次登入，以便工作階段儲存在 `cookies.sqlite` 中。
