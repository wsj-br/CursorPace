# Cursor Pace 0.3.5 Release Notes

## Highlights

- On the live cycle, the next renewal card shows how long remains until that instant, in the same compact form as the back-on-pace wait.

## Why this release matters

The cycle summary now shows the time left until renewal beside the renewal date, so the wait is visible on the same card as the date.

## Install

Download the package for your platform from this release:

- Windows: `CursorPace-0.3.5-win-x64-setup.exe`. The build is unsigned, so SmartScreen may ask you to choose **More info**, then **Run anyway**. **Sign in** needs the Microsoft Edge WebView2 Runtime; the installer offers the download page if it is missing.
- Linux: `CursorPace-0.3.5-linux-x64.AppImage` or `CursorPace-0.3.5-linux-arm64.AppImage`. Make the file executable (`chmod +x`) before running it. On Debian or Ubuntu, `CursorPace-0.3.5-linux-x64.deb` or `CursorPace-0.3.5-linux-arm64.deb` installs with `sudo apt install ./CursorPace-*.deb` and pulls GTK/WebKit dependencies.
- macOS: `CursorPace-0.3.5-osx-arm64.dmg` or `CursorPace-0.3.5-osx-x64.dmg`. Open the DMG and drag `CursorPace.app` to Applications, then right-click **Open** the first time to bypass Gatekeeper (the build is unsigned).
