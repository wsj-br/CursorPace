## 설치

이 저장소의 릴리스 페이지에서 빌드를 다운로드하세요.

**Windows.** `CursorPace-*-win-x64-setup.exe`을(를) 실행하세요. SmartScreen에서 앱이 서명되지 않았다고 경고하면 **추가 정보**를 선택한 다음 **실행**을 선택하세요. **로그인**하려면 [Microsoft Edge WebView2 런타임](https://go.microsoft.com/fwlink/p/?LinkId=2124703)이 필요합니다. 설치 프로그램은 런타임이 없을 때 다운로드 페이지를 제공합니다.

**Linux.** 대부분의 배포판에서는 `chmod +x CursorPace-*-linux-x64.AppImage`(또는 `linux-arm64` 파일)을 다운로드하여 실행하세요. Debian 또는 Ubuntu에서는 `sudo apt install ./CursorPace-*-linux-x64.deb`(또는 `linux-arm64`)이 GTK와 WebKit을 가져옵니다. Google 로그인은 WebKit에서 차단될 수 있습니다. GitHub, 이메일을 사용하거나 Windows에서 로그인하세요.

**macOS.** `CursorPace-*-osx-arm64.dmg`(Apple Silicon) 또는 `*-osx-x64.dmg`(Intel)을 열고 `CursorPace.app`를 응용 프로그램 폴더로 드래그하세요. Gatekeeper가 서명되지 않은 앱을 차단하면 **열기**를 한 번 마우스 오른쪽 버튼으로 클릭한 다음 **시스템 설정 → 개인정보 보호 및 보안**에서 **무시하고 열기**를 선택하세요.

## 첫 실행

**알림 트레이에서 시작**이 기본적으로 켜져 있으므로 처음 실행 시 트레이 아이콘만 표시될 수 있습니다. 해당 아이콘에서 창을 열거나 `--show`을(를) 사용하여 실행하세요.

1. **로그인**을 선택하세요.
2. 내장된 창에서 Google, GitHub 또는 2단계 인증 로그인을 완료하세요. Cursor가 세션을 수락하면 창이 닫힙니다. 이미 계정이 표시되면 **계속**을 선택하세요.
3. 청구 주기와 사용량이 차트에 나타납니다.

나중에 **설정** → **Cursor 계정**에서 로그인할 수 있습니다. 성공적으로 업데이트되면 해당 제목이 **Cursor 계정 (연결됨)** 으로 표시됩니다. 제목 표시줄의 **새로 고침** 또는 설정의 **지금 새로 고침**을 사용하여 즉시 가져옵니다.

**로그아웃**은 Cursor 세션을 지웁니다. Windows와 macOS에서는 저장된 Google 또는 GitHub 로그인이 남아 있을 수 있으므로 다음 로그인 시 비밀번호를 건너뛸 수 있습니다. Linux에서 **로그아웃**은 전체 브라우저 프로필을 지웁니다. 사용량 샘플은 디스크에 남아 있습니다.

**사용량 자동 업데이트**가 켜져 있으면 자정부터 1, 2, 4, 6 또는 12시간 단위로 새로 고침이 수행됩니다. 시작 시 마지막 성공이 최소 20분 전이고 예약된 시간대를 놓쳤거나 전체 간격이 이미 경과한 경우에만 새로 고침이 실행됩니다.

## 메인 창

</p>

차트 위에 세 개의 카드가 있습니다:

- **청구 주기 시작** 및 **다음 갱신**. 현재 주기에서는 갱신 날짜 옆에 남은 시간이 표시됩니다.
- 각 모델에 대한 예측. 주기 내에서는 소진 시간입니다. 점선 예상선 위에서는 해당 선이 수치에 도달하는 시점입니다. 선 위 또는 선 위에서는 갱신 시 예상 백분율입니다. 현재 주기에서는 날짜 옆에 대기 시간이 포함됩니다.
- **마지막 측정**: 이 주기의 최신 샘플로, Cursor %, 기타 %, 예상 사용량 % 및 각 계열이 해당 속도에서 얼마나 떨어져 있는지를 보여줍니다.

월 제목의 이전 및 다음 버튼으로 저장된 주기를 탐색합니다. 해당 제목 아래 `Cursor dd-MMM HH:mm`은(는) 가장 최근 새로 고침입니다. 빨간 점은 계정이 로그아웃되었거나 새로 고침에 실패했음을 의미합니다. 클릭하여 **Cursor 계정**을 엽니다. 동기화 서버가 구성된 경우 **동기화 서버**와 마지막 성공 시간도 거기에 표시됩니다. 빨간 점은 마지막 시도가 실패했음을 의미합니다. 클릭하여 **동기화 서버**를 엽니다.

| 범위 | 표시 내용 |
| --- | --- |
| **1일** / **2D** | 최근 24시간 또는 48시간 |
| **7D** / **1W** | 지난 7일 |
| **2W** | 지난 14일 |
| **1M** | 표시된 전체 주기, 현지 날짜당 샘플 1개 |

현재 주기에서는 짧은 범위가 현재 시간에 끝납니다. 이전 주기에서는 해당 주기의 갱신 시점에 끝납니다. 창이 그보다 일찍 시작될 경우 시작 시점은 청구 주기 시작 시점에 유지됩니다.

플롯을 드래그하여 확대/축소합니다. 마우스 오른쪽 버튼을 클릭하면 **1개월**로 돌아갑니다. 이미 선택된 버튼을 포함하여 범위 버튼을 선택하면 확대/축소 모드를 종료하고 해당 범위를 표시합니다. **다음까지 모든 샘플** (**2D**, **4D**, **7D**, 또는 **14D**, 기본값 **14D**)는 차트가 모든 샘플을 얼마나 멀리 플로팅하고 현지 시간을 레이블링할지 설정합니다. 더 긴 범위는 각 날짜의 마지막 샘플을 유지하고 월의 날짜를 레이블링합니다. 세로 축은 화면의 값을 최대 120%까지 맞춥니다.

포인터를 이동하여 해당 시점의 Cursor, 기타 모델 및 예상 사용량을 확인합니다. 마지막 샘플 이후에는 Cursor와 기타 모델이 `estimated`으로 표시된 예상치를 보여줍니다. 확대/축소 중에는 판독값이 확대/축소 시작 시점의 각 값과 거기서부터의 변화도 보여줍니다.

| 제어 | 작업 |
| --- | --- |
| **새로 고침** | 지금 Cursor 사용량을 가져옵니다. 설정 페이지에서는 숨겨집니다. |
| **설정** | 이 창에서 설정 열기 |
| **뒤로** | 차트로 돌아가기 |
| **최소화** / **최대화** | 표준 창 컨트롤. 앱은 트레이에 유지됩니다. |
| 닫기 | 창을 숨깁니다. 앱은 트레이에 유지됩니다. |

창은 크기, 위치 및 최대화된 상태를 기억합니다. 정보 레이블은 선택하고 복사할 수 있습니다.

## 예상 및 추정

- **예상 사용량**은 차트에서 청구 주기 시작 시점의 0%부터 다음 갱신 시점의 100%까지 이어지는 점선입니다. 호버 시 이 선이 사용됩니다.
- **Cursor** 및 **기타 모델**은 측정된 샘플입니다.
- 주기 CSV의 **예상**은 각 샘플을 따르며, 남은 할당량을 갱신 시점까지 100%로 조정합니다.
- **예측**은 마지막 샘플부터 갱신까지의 둥근 점선 투영입니다. 마지막 샘플 이후에는 호버 시 이 선이 사용됩니다.

Cursor 모델과 기타 모델은 독립적으로 유지됩니다.

## 설정

설정은 차트를 대체합니다. **뒤로** 또는 **설정** 제목을 클릭하면 차트로 돌아갑니다. 마지막 탭은 다시 시작한 후에도 다음번에 다시 열립니다.

**동기화 서버**는 선택 사항입니다. [CursorPace 동기화 서버](https://github.com/wsj-br/CursorPace-SyncServer)는 로컬 네트워크의 여러 컴퓨터에서 사용량 샘플과 청구 주기 경계를 공유하므로, 동일한 개발 환경에 있는 Mac, Windows PC 및 Linux 머신이 동일한 차트를 표시합니다. 해당 저장소에서 서버를 설치하고 실행하십시오. 테마, 언어, 창 배치 및 시작 옵션은 각 컴퓨터에 유지됩니다.

| 탭 | 설정 가능한 항목 |
| --- | --- |
| 시작 및 표시 | **로그인 시 실행**, **알림 트레이에서 시작**, 테마 (시스템, 라이트 또는 다크), **언어** (`locales/ui-languages.json`에 있는 로케일 또는 해당 파일이 없을 경우 영어), 및 **다음까지 모든 샘플** |
| Cursor 계정 | **로그인** (연결된 동안 숨겨짐), **지금 새로 고침**, **로그아웃**, 및 1, 2, 4, 6 또는 12시간마다 자동 새로 고침 |
| 동기화 서버 | **서버와 동기화**, 서버 URL, API 토큰, 컴퓨터 이름(기본적으로 호스트 이름) 및 **지금 다시 동기화**. 이 링크는 동기화 서버 저장소를 엽니다. |
| 내보내기 및 백업 | 화면에 표시된 주기에 대한 **주기 CSV 내보내기**, 로그인된 동안 저장된 모든 샘플에 대한 **사용량 내보내기**, 그리고 설정 및 샘플을 하나의 ZIP 파일로 **백업** / **복원**. **폴더 열기**는 대상 폴더를 엽니다. |
| 정보 | 버전, UTC 빌드 날짜 및 시간, 저작권, MIT 라이선스 및 GitHub 저장소 |

백업 및 복원 시 이 컴퓨터의 Cursor 로그인 정보는 유지됩니다.

## 트레이

아이콘을 클릭하거나 **열기**를 선택하여 창을 표시합니다. **종료**를 선택하면 앱이 종료됩니다. 도구 설명에는 오늘의 백분율과 충분한 데이터가 있을 경우 갱신 시 예상 백분율이 표시됩니다.

macOS에서는 클릭하면 트레이 메뉴가 열리고, 창이 숨겨지거나 최소화되면 Dock 아이콘이 숨겨집니다. 트레이에서, `--show`를 사용하여, 또는 앱을 다시 실행하여 창을 표시할 수 있습니다.

아이콘이 보이지 않으면 알림 오버플로를 엽니다. GNOME에서는 AppIndicator 확장이 필요할 수 있습니다.

두 번째 실행 시 이미 실행 중인 창이 표시됩니다. 두 번째 `--background` 실행 시 창은 숨겨진 상태로 유지됩니다. `--show`는 창을 강제로 엽니다. **로그인 시 실행**은 **알림 트레이에서 시작** 설정을 따릅니다.

## 데이터

```text
Windows: %LocalAppData%\CursorPace\
Linux:   ~/.local/share/CursorPace/
macOS:   ~/Library/Application Support/CursorPace/
```

`settings.json`에는 기본 설정, 창 배치 및 주기 범위가 저장됩니다. `usage-samples.json`에는 샘플이 저장됩니다. Cursor 로그인 정보는 Windows의 `WebView2`, Linux 및 macOS의 `WebView`, 또는 Linux AppImage 실행 시 `WebView-AppImage`에 저장됩니다. 구문 분석할 수 없는 파일은 `*.corrupt.json`로 복사되고 빈 파일로 대체됩니다. 잠겨 있거나 읽을 수 없는 파일은 그대로 유지됩니다.

다시 시작하려면 폴더를 삭제하십시오. Windows에서는 앱을 제거하면 해당 폴더가 제거됩니다. Linux 및 macOS에서는 직접 삭제해야 합니다.

## 갱신

새로운 청구 주기 시작을 보고하는 가져오기는 이전 청구 주기를 보관하고 해당 샘플을 유지합니다. 이전 및 다음 버튼으로 해당 주기를 열 수 있습니다. 앱은 또한 로컬 날짜가 저장된 갱신 날짜에 도달하면 새로 고쳐집니다. 창은 숨겨진 상태로 유지될 수 있습니다. 해당 확인 및 자동 업데이트를 위해서는 프로세스가 실행 중이어야 합니다.

## 제거

트레이 메뉴에서 종료합니다. Windows에서는 **설치된 앱**에서 **CursorPace**를 제거합니다. Linux 및 macOS에서는 앱을 삭제하고, 깨끗하게 다시 시작하려면 위에 언급된 데이터 폴더를 삭제하십시오.

## 문제 해결

**앱이 시작되지 않습니다.** 모든 `CursorPace` 프로세스를 종료하고 다시 실행하십시오. Windows에서는 이벤트 뷰어를 확인하십시오. Linux에서는 `journalctl --user -xe`을 시도하십시오. macOS에서는 Console.app을 확인하십시오. Linux CPU 사용률이 100%이거나 `crash.log`에 `Could not create glyphTypeface`라고 표시되면 0.3.0보다 최신 릴리스를 설치하십시오. **로그인 시 실행**이 삭제된 AppImage를 계속 가리키는 경우, 새 AppImage를 한 번 실행하십시오.

**로그인에 실패하거나 "지정된 모듈을 찾을 수 없습니다."** Windows에서는 [WebView2 런타임](https://go.microsoft.com/fwlink/p/?LinkId=2124703) (Evergreen x64)을 설치하십시오. Linux에서는 `libwebkit2gtk-4.1-0`을 설치하십시오. Google이 내장 브라우저를 차단하는 경우 GitHub 또는 이메일을 사용하십시오. 화면에 이미 Cursor 계정이 표시되어 있으면 **계속**을 선택하십시오.

**사용량이 업데이트되지 않습니다.** **Cursor 계정 (연결됨)** 및 자동 업데이트를 확인하거나 **새로 고침**을 선택하십시오. 시스템 날짜, 시간 및 시간대를 확인하십시오. Cursor 속도 제한에 도달하면 앱은 다음 간격까지 기다립니다.

**트레이 또는 작업 표시줄 아이콘이 없습니다.** 알림 오버플로를 엽니다. Linux에서는 앱이 `~/.local/share/applications/CursorPace.desktop`을(를) 쓸 수 있도록 앱을 다시 시작합니다. 작업 표시줄 아이콘이 여전히 일반적인 톱니바퀴 모양이라면 한 번 로그아웃하거나, X11에서는 Alt+F2를 누르고 `r`을(를) 입력한 다음 Enter를 누릅니다.

**설정이 저장되지 않거나 오늘 백분율이 잘못된 것 같습니다.** 데이터 폴더에 쓰기 권한이 있는지 확인하세요. `settings.corrupt.json`이(가) 있다면 삭제하고 `settings.json`하여 재설정하세요. 그런 다음 시계를 확인하고 **새로 고침**을 선택하세요.

**로그인 시 실행**이 작동하지 않습니다. 설정이 켜져 있는지 확인하세요.
